## About

I'm a B.Tech student in **Artificial Intelligence & Data Science** at
**Amrita Vishwa Vidyapeetham, Faridabad**.

Most of my work so far has been through academic and independent
projects. I enjoy taking a problem from the initial idea through data
preparation, implementation, testing, and evaluation. I'm especially
interested in **computer vision and medical imaging, probabilistic
modelling, and high-performance computing**. I've also worked on
big-data applications and control-system simulations.

I try to keep the assumptions, implementation details, and evaluation
visible in my projects so that the work can be understood and
reproduced---not just viewed as a final score.

## Selected Projects

### [MSF-HSAT --- 3D Lung Tumor Segmentation](https://github.com/Bhargav12-surya/CV-lung-segmentation-)

A 3D CT segmentation project exploring multi-scale feature fusion,
wavelet-based attention, and transformer components for lung-tumor
segmentation. The work is evaluated against a 3D U-Net baseline, with
validation and held-out test results kept separate.

`Python` `PyTorch` `3D CNN` `Transformers` `Medical Imaging`

*Research prototype for academic use; not a clinical diagnostic system.*

### [ElastoRisk --- Probabilistic Reliability Analysis](https://github.com/Bhargav12-surya/elastorisk-mis-phase-2-)

A reliability-analysis project built around ultrasound elastography. It
uses a Bayesian network, an EM-learned two-state latent quality
representation, exact probabilistic inference (including missing
indicators), and spatial reasoning with HMM/MRF methods. The evaluation
uses held-out synthetic records and focuses on image-quality reliability
rather than clinical diagnosis.

`Python` `Bayesian Networks` `Expectation–Maximization` `HMM` `MRF`

*Research/course prototype; it does not estimate cancer probability or
provide clinical advice.*

### [Parallel and GPU-Accelerated HFT Simulation Engine](https://github.com/Bhargav12-surya/parallel-hft-engine-HPC)

An event-driven trading simulator with a deterministic C17 order-book
engine. It compares sequential and threaded CPU execution with OpenMP,
MPI, CUDA, and hybrid execution paths. The project also includes
synthetic market-event generation, AI strategy inference, benchmarking,
and a terminal interface for running experiments.

`C17` `OpenMP` `MPI` `CUDA` `Python` `HPC`

*Educational simulator using generated data; it does not connect to an
exchange or place live trades.*

### [Smart Biomedical Infusion Control System](https://github.com/Bhargav12-surya/Smart-Biomedical-Infusion-of-Control-System)

A closed-loop flow-regulation simulation that studies how a controller
responds to changes in downstream pressure and tubing resistance. The
project compares a PI-plus-feedforward baseline with a neuro-fuzzy
controller, with both passing through a common safety supervisor. It
includes MATLAB/Simulink work and an ESP32-based demonstration setup.

`MATLAB` `Simulink` `Control Systems` `Neuro-Fuzzy Logic` `ESP32`

*Educational benchtop prototype only; not intended for use on a person
or for clinical infusion.*

### [CineScope --- Movie Review and Recommendation System](https://github.com/Bhargav12-surya/Movie-review-and-Recommendation-TA_BDA-)

A movie review analysis and recommendation project combining big-data
processing with an interactive application. The work brings together
Spark and Scala pipelines, sentiment and aspect-level review analysis,
recommendation workflows, and a local web interface.

`Python` `Scala` `Apache Spark` `MLlib` `FastAPI` `SQLite`

### [IMI --- Hybrid Multi-Modal Crystal Property Predictor](https://github.com/Bhargav12-surya/DL_IMI_ETP)

A materials-informatics project that combines EBSD microstructure
images, crystallographic texture images, and grain-boundary graph data.
Its model design uses separate ResNet50, MobileNetV2, and CGCNN
branches, followed by a fusion network for material-property prediction.

`Python` `PyTorch` `ResNet50` `MobileNetV2` `CGCNN` `React`
